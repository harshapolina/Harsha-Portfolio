# Harsha Polina — Portfolio

Personal portfolio site for **Harsha Polina** — founder at Editco Media, full stack developer, and AI solutions builder.

## Stack

- Next.js 15 (App Router)
- React 19
- Tailwind CSS
- GSAP + ScrollTrigger
- Matter.js (W'IK? stack fall)
- Motion (TrueFocus)

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Dev server (Turbopack) |
| `npm run build` | Production build |
| `npm start` | Serve production build |
| `npm run lint` | ESLint |

## Deploy
